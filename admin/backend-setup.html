Configuration Backend Réel
Passez de localStorage à Firebase ou Supabase pour une vraie base de données
Mode: localStorage
Option 1: Firebase (Google) - Recommandé

Gratuit, temps réel, facile. Idéal pour GOBEX.

  1. Allez sur console.firebase.google.com
  2. Créez un projet "gobex-bj"
  3. Activez Firestore Database
  4. Créez une collection gobex_products
  5. Copiez la config ci-dessous
{ "apiKey": "AIza...", "authDomain": "gobex-bj.firebaseapp.com", "projectId": "gobex-bj", "storageBucket": "gobex-bj.appspot.com", "messagingSenderId": "123456789", "appId": "1:123456789:web:abc" }
Option 2: Supabase (Open Source)

Alternative open source, PostgreSQL, gratuit.

  1. Allez sur supabase.com
  2. Créez un projet "gobex"
  3. Créez une table gobex_products avec colonnes: name, category, price, etc.
  4. Récupérez URL + anonKey
Mode actuel : localStorage (navigateur)

En mode localStorage, vos produits sont stockés uniquement dans votre navigateur. Ils ne sont pas visibles par les autres visiteurs.

Pour que tout le monde voie vos modifications : activez Firebase ou Supabase ci-dessus. C'est gratuit et prend 5 minutes.

Structure table Supabase / Firestore
Table: gobex_products - id (auto) - name (text) - category (text: logiciel/document/formation) - price (int) - oldPrice (int) - badge (text) - desc (text) - image (text) - whatsapp (text) - meta1, meta2 (text) - active (bool) - created_at (timestamp) Table: gobex_orders - id, customer_name, product, price, status, date Table: gobex_settings - cabinetName, phone, whatsapp, email, address, ifu, rccm
