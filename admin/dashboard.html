Comment fonctionne l'ADMIN ?

Ce panel admin utilise localStorage (stockage navigateur). Vos modifications de produits sont sauvegardées localement et s'affichent instantanément sur la boutique. Pour une vraie base de données, il faudra connecter un backend (Firebase, Supabase, ou API PHP). En attendant, vous pouvez exporter vos données en JSON.
