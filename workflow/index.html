Workflow détaché — comment ça marche ?
  • Indépendant : ce portail vit à /workflow/ (hub + /workflow/fiscalite.html), séparé du site GOBEX pour ne pas surcharger l'application. Il peut être déployé seul, mis à jour sans toucher au site.
  • Accès par bouton : seul un bouton “Workflow” dans l'admin (visible uniquement par l'administrateur ou les personnes désignées) y donne accès. Pas de lien dans le menu public.
  • Données : même origine → localStorage partagé (gobex_exec_dossiers / gobex_crm_clients) si besoin, mais le workflow peut aussi fonctionner avec sa propre base (import/export JSON) pour rester autonome.
  • Sécurité : vérif gobex_admin_auth + gobex_workflow_access — l'admin désigne qui voit le bouton et qui ouvre chaque workflow.
